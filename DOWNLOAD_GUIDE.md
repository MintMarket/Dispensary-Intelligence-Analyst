# How to Download This Project

## Option 1: Download ZIP File (Easiest!)

### Step-by-Step:

1. **Go to the GitHub page**
   - The project is at: `https://github.com/MintMarket/Dispensary-Intelligence-Analyst`
   - (Or wherever your repository is hosted)

2. **Click the green "Code" button**
   - It's near the top right of the page
   - Look for a button that says "Code" with a down arrow ▼

3. **Click "Download ZIP"**
   - A menu will appear
   - Click "Download ZIP" at the bottom
   - The file will download to your computer (usually your Downloads folder)

4. **Unzip the file**
   - **Windows:** Right-click the ZIP file → Click "Extract All" → Click "Extract"
   - **Mac:** Double-click the ZIP file
   - You'll now have a folder called `Dispensary-Intelligence-Analyst-main` or similar

5. **Move the folder somewhere easy to find**
   - Good places:
     - Windows: `C:\Users\YourName\Documents\`
     - Mac: Your `Documents` folder or `Desktop`

6. **Rename the folder (optional)**
   - Remove the `-main` part if it's there
   - Just call it: `Dispensary-Intelligence-Analyst`

✅ **Done!** Now you have all the files and can follow the setup guide.

## Option 2: Use Git Clone (If You Know Git)

If you have Git installed, you can clone the repository:

```bash
git clone https://github.com/MintMarket/Dispensary-Intelligence-Analyst.git
cd Dispensary-Intelligence-Analyst
```

## What You're Downloading

You're downloading all the files that make up the Dispensary Intelligence Analyst system:
- The program code
- Example reports
- Setup scripts
- Documentation

**Size:** About 2-5 MB (very small)

**Time:** Usually takes less than 1 minute to download

## After Downloading

Once you have the folder on your computer:

1. ✅ **You have:** All the project files
2. ➡️ **Next step:** Install Node.js (see SETUP_GUIDE.md)
3. ➡️ **Then:** Run setup.bat (Windows) or setup.sh (Mac)
4. ➡️ **Finally:** Run your first report!
